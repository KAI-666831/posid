# 收銀＋證件

收銀（快速收銀）＋ 身分證辨識 合在一個 app。

流程：收銀選好品項 → 按「結帳 → 掃證件」→ 自動進連續掃描 → 掃滿人數自動回收銀，接下一組客人。

- 要掃幾位 = 有 👤 標記的商品數量加總（例如 釣手×3 + 觀光×2 = 5 位）。
  到「設定 / 備份」每個商品右邊的 👤 可以開關；名稱有「釣手／觀光／船票／乘客」預設就是開的。
- 之前存過的客人掃到也算這組 1 位。
- 中途按「取消／完成」可以提早回收銀。
- 掃到的資料在上方「證件／名單」分頁，匯出 CSV、進出港名單都跟原本一樣。

## 雙機模式（一支收銀、一支掃描）

兩支手機都裝這個 app，到「證件／名單」最上面的「雙機模式」：
1. 收銀那支選「收銀機」，會顯示一組 8 碼配對碼。
2. 掃描那支選「掃描機」，輸入那組配對碼。
3. 收銀機結帳 → 掃描機自動開相機（本組 0/5 位）→ 掃滿自動接下一組；收銀機會跳「這組證件掃好了」。

兩支都要有網路。證件資料只存在掃描機，名單、匯出都在掃描機上做。

## 分組：先結帳，證件等一下一起掃

收銀頁有兩個結帳鈕：
- 「結帳 → 馬上掃證件」：結完直接開相機掃這組。
- 「結帳・證件等一下一起掃」：先記成「第N組」排隊，上方出現「📷 待掃 N」，按下去依序掃第1組、第2組…，一組掃滿自動換下一組。

每組會記下買了什麼（人頭和單品都列）和金額；掃到的人會標上是第幾組。
「證件／名單」頁的「今日各組」可以看每組買了什麼、掃到誰，沒掃滿的可以「補掃」。
